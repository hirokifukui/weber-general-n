$h(a)=H(u_a)$ is additive in $a$ (\path{WeberSH.H_pow}: $H(u^k)=kH(u)$, and $u_{a+b}=\pm u_au_b$ is invisible to $H$), so Theorem~\ref{thm:SH} applies once (Car) is verified for every $a\in L$.

\emph{Base branch ($a\in\ell R$).} Write $a=\ell b$ with $b\in R$. Then $u_b\in A\subseteq U$ and $u_b^{\ell}=\pm u_a$, so $\ell H(u_b)=H(u_a)=h(a)$ (\path{WeberSH.base_branch}).

\emph{Saturation branch ($a\in L\setminus\ell R$).} By (Sat) there is $u\in U$ with $u^{\ell}=u_a$; then $\ell H(u)=H(u_a)=h(a)$ (\path{WeberSH.sat_root_log}).

In both branches the carrier exists; Theorem~\ref{thm:SH} gives $\ell^{d}\le K_mD/L_0^{m}$. (For a unit $u$ of a totally real field, $H(u)=0$ iff all conjugates are $\pm1$ iff $u=\pm1$; so (Floor) in the form ``$u\ne\pm1\Rightarrow\hgt(u)\ge L_0$'' is the same hypothesis.)
