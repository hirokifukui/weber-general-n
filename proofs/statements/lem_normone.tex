$a=1+3^n$ has exact order $3$ modulo $q$ and $\tau$ acts by $\zeta\mapsto\zeta^{a}$; $\operatorname{Nr}_{B_{3,n}/B_{3,n-1}}(\eta_n)=1$. If $\eta_n^{\alpha_\sigma}=\varepsilon^{\ell}$ with $\alpha_\sigma\in\Z[G]$, $\varepsilon\in E_{3,n}$, $\ell$ an odd prime, then $\operatorname{Nr}_{B_{3,n}/B_{3,n-1}}(\varepsilon)=1$. In general, for $\varepsilon\in E_{3,n-1}$ one has $\operatorname{Nr}_{B_{3,n}/B_{3,n-1}}(\varepsilon)=\varepsilon^3$, so a unit of the lower layer with relative norm $1$ equals $1$; hence a unit of relative norm $1$ with $H(\varepsilon)\ne0$ is not in $E_{3,n-1}$.
