Let $t\ge1$, $\ell$ an odd integer and $x,y\in\mathcal O_n^\times$. Then $x^\ell\equiv1\pmod{2^t\mathcal O_n}$ if and only if $x\equiv1\pmod{2^t\mathcal O_n}$; more generally $x^\ell\equiv y^\ell\pmod{2^t\mathcal O_n}$ if and only if $x\equiv y\pmod{2^t\mathcal O_n}$.
